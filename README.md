# 🦆📋️ DuckyPaste

DuckyPaste is a small quick project I made for stardance's project 'Frictionless' providing a solution to a tricky problem, unreliable clipboards. DuckyPaste, while operating systems have built in tools for a clipboard, makes it simple to access and easy-to-use.

By implementing pinning of certain entries and the deletion of certain entries, users can not only view their clipboard, but manage it, a primary function of DuckyPaste. 

**Features:**

    🔨 Simple Functionality

    📌 Pinning and Unpinning Functionality

    🗑️ Deleting and Managing the clipboard

    🧰 Accessible from the toolbar

    📦️ Always backed up a .json file so it doesn't corrupt

**Supported Platforms:**

DuckyPaste has been tested on:

    ✅ Windows 10/11
    
    ✅ Arch Linux (toolbox icon does not function)

**Installation**

```
1. Clone the repository: git clone https://github.com/YOUR_USERNAME/DuckyPaste.git cd DuckyPaste
2. Install dependencies pip install . (The project uses uv for the arch fork)
3. Run the app
python src/main.py
macOS Gatekeeper
```

If macOS prevents the application from opening:

    Attempt to run the application once.
    Open System Settings → Privacy & Security.
    Scroll down to the security warning.
    Click Open Anyway.

If running from source, use:

    python3 src/main.py
